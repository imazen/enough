# how-far measurements — 2026-10-06

Source: commit `2bcc73a` (working tree identical). Host: AMD Ryzen 9 9950X3D,
WSL2, 32 threads. Instruction counts come from `perf stat -e instructions:u`
and do not depend on machine load; cycles depend on it far less than wall time.
This record replaces the dated records of earlier designs, which remain in the
git history.

## Real encoder adoption

`python3 dev/adopt-zenpng.py ~/work/zen/zenpng <dir>` materializes zenpng
`27393eef` with feature-gated progress, then
`cargo test --manifest-path <dir>/probe/Cargo.toml --features progress`:
three tests pass (byte-identical serial and parallel output with tracked
strategy counts, cancellation after real encoder work, and the old
cancellation API preserved).

Not measured here: wall-time overhead (zenbench), cold-build wall time, and the
zenresize and zenav1-svt integrations, which still use earlier APIs.
